# 05 · 覆写到底能不能恢复：Clear vs Purge

排查过程中被问到的问题：**「一次全盘写零之后，旧数据还能找回来吗？」**

## 技术结论：不能

磨盘那套「覆盖了也能恢复」的传说，来自一项**真实存在**的技术：**磁力显微镜（MFM）**。它确实能成像磁畴的残余图案。但：

- 它只在**老式、低密度、纵向记录**的介质上有效 —— 那时磁道宽、位元大，前一次写入的残余磁场还能被针尖分辨
- 现代硬盘是**垂直记录**，面密度高到前一次写入的残余信号**远低于噪声底**，也远低于 MFM 针尖的空间分辨率
- 而且**每个扇区带自己的 ECC**。读通道按误码率 1e-15 量级设计 —— 残余信号比这还弱好几个数量级，连「读出错了」都触发不了

**Gutmann 自己在论文里就否定了那个误传**：35 遍方案是为 MFM/RLL 那类「逻辑位和物理位一对一映射」的老编码设计的。对现代盘，**单遍随机覆写就够了**。后来所有人都拿他当「要覆写 35 遍」的依据，恰恰相反。

### 把最强的一方论证也放上来

用**零**（已知图案）覆写，理论上比随机覆写**更有利**于检测残余 —— 因为你精确知道每个磁畴「应该」是什么状态，任何偏差都是候选残余信号。

**但量级仍然差着天文数字。** 这不是「理论上不可能」，而是「**没有已知手段**」——一个操作性结论，不是数学证明。

## 标准机构的划分：NIST SP 800-88r1

媒体消毒规范把处置分两档：

| 级别 | 手段 | 能防住谁 |
|---|---|---|
| **Clear** | 覆写一遍 | 挡住**所有常规**恢复手段（软件、实验室常规流程）|
| **Purge** | ATA Secure Erase / 消磁 / 物理销毁 | 挡住**实验室级**攻击 |

- **一次全盘写零 = 完整的 Clear。** 对普通数据，这就到头了。
- **高敏感度数据**规范要求的不是 Clear，是 **Purge** 或销毁。

## 实践建议

### 如果你只是想安全地处理一块二手盘

一次全盘覆写（`diskpart clean all`）**就已经达到了规范意义上的正确消毒**。这比「把文件删掉然后卖掉」高出一个量级。

### 如果你怀疑盘上有高敏感度数据

那么正确的下一步**不是找恢复工具**：

1. **联系上游/相关方**（上家、或所属单位的相关部门）。一块可能装过敏感材料的介质流入二手市场，是个**安全事件**，而事件主体是**上一个持有人**。
2. **那块盘的正确归宿是消磁或物理粉碎**，而不是「清干净之后接着用来存自己的东西」。
3. 该被问的问题从来不是「我能不能把它读回来」，而是「**上一个主人为什么不先把它清干净就卖了**」。

## 「先镜像，再动手」是唯一正确的顺序

想扫旧数据：

1. **先只读整盘镜像**（`ddrescue` 到另一块盘）
2. **在镜像上**跑恢复工具
3. **确认真的不要了，才允许写第一个字节**

```bash
ddrescue -f -n /dev/sdX /mnt/backup/disk.img /mnt/backup/disk.map
```

顺序颠倒就是不可逆的。而「打开盘看看有没有文件」**不构成确认** —— 它只反映当前的文件系统元数据。
