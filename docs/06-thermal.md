# 06 · 温度与盒子散热

SMART 的健康位里**没有温度**。温控是完全独立的一件事，而且它有自己的坑。

---

## 一、先拿「这块盘自己的」上限，别猜

每块盘的规格上限**不一样**，而且**盘自己会把它报出来**：

```powershell
& $sc -l devstat -d sat /dev/sdX | Select-String 'Specified Maximum Operating Temperature'
```

实测三块盘：**55 / 60 / 65 °C**。别按「硬盘一般 60 度」去估 —— 差 5 度在边缘情况下就是合格与不合格的分界。

> ⚠️ 注意 devstat 的格式是「**数值在前、标签在后**」：
> `0x05  0x058  1   55  ---  Specified Maximum Operating Temperature`
> 写正则时要 `(\d+)\s+\S+\s+标签`，反过来匹配不到（这个错我犯了两次）。

同时记下这两个字段 —— 它们是**写在盘里的终身记录，不能清零**：

| 字段 | 含义 |
|---|---|
| `Highest Temperature` | 终身最高温 |
| `Time in Over-Temperature` | 在上限之上累计的**分钟数** |

以及属性 194 的终身极值：

```
194 Temperature_Celsius  ...  46 (Min/Max 4/61)
                               ↑当前      ↑终身最低/最高
```

## 二、实测案例：无风扇 + 叠放 + 贴木桌

三块盘（一块 2.5" 7200 转、一块 3.5" 5400 转、一块 2.5" 5400 转），**无风扇、三块叠放、放在木桌上**，全程空载，监控 6 小时 23 分。

| 盘 | 平均 | 最高 | 上限 | **超限时间占比** |
|---|---|---|---|---|
| **7200 转，夹在中间** | **57.2 °C** | **61 °C** | 55 °C | **73.6 %** |
| 2.5"，最上层 | 43.9 °C | 48 °C | 60 °C | 0 % |
| 5400 转，最下层 | 46.6 °C | 52 °C | 65 °C | 0 % |

**只有一块被烤了，而且它不是「稍微冒一下」，是稳态就在线外 2–4 度。**

按小时的均值，它一天的走势：

```
13:00  48.6  →  14:00  57.9  →  15:00  60.6  →  16:00  59.7  →  17:00  59.0
```

**14 点之后再也没有回到 55 以下。** 这是热平衡点在线外，不是暂态。

而它的终身记录被永久改写：`Highest Temperature` 54 → **61**，`Time in Over-Temperature` 0 → **280 分钟**。

## 三、为什么铝壳救不了它

铝比塑料好 —— 但前提是**得有风**。热量要走完这条路：

```
盘体（金属底盘） → ① 盒内空气 → ② 铝壳 → ③ 室内空气
```

- **① 几乎传不动**：空气导热系数 **0.026 W/(m·K)**，铝是 **237** —— 差 **9000 倍**。而且多数盒子用**橡胶减震垫 / 塑料导轨**固定硬盘（为了减震），那是**绝热体**。
- **② 无风时也出不去**：静止空气里只有自然对流，而自然对流需要空气**流动**。没有风，铝壳唯一能做的事是「把自己整体加热到跟内部一样热」，然后停住。
- **叠放时铝的优点变成缺点**：铝的高导热率让三个壳变成**热量共享总线** —— 每块盘的热被平均分给邻居，谁都跑不掉。

### 用手验证（关键诊断，30 秒）

摸一下外壳：

| 手感 | 说明 | 对策 |
|---|---|---|
| **烫得放不住手**（>55 °C） | 盘和壳之间**有传导路径**（比如螺丝直接拧在铝壳上） | 给它风就立竿见影 |
| **只是温热**，能一直按着 | 热**卡在盒内空气里**，传不到壳 | 得让空气能进盒子（开孔 / 拆顶盖） |

（59 °C 的水摸着是疼的 —— 所以如果你能舒舒服服把手按在壳上，就说明壳的温度远低于 59。）

### 一个有用的反向推论

**如果壳是铝的，那吹它任何一个位置都有效。** 铝的内部热阻极低，热量会迅速铺满整个表面 —— 不需要找进风口、不需要对准散热孔，**风扇贴着壳侧面横吹就够了**。塑料壳做不到这一点（塑料导热系数只有 ~0.2，吹到的地方凉、旁边还是热的）。

## 四、免费且最有效的三步（不用买任何东西）

按收益排序：

1. **别叠放** —— 尤其别把最热那块夹在中间。实测规律：**谁在最上面谁最凉**（只有一面受热，顶面自由散热）；最底下那块最热（桌面是绝热体 + 上面一块压着）。
2. **立起来，像书一样排开，留 1 cm 缝** —— 3.5" 盒子立起来每块只占约 12 × 3.5 cm，**三块立着（约 12 × 13 cm）比叠着（18 × 12 cm）占地还小**，而两个 18 × 12 的大面全部暴露，垂直缝隙还能形成自然对流。3.5" 盘的厂商规格**明确支持垂直安装**。
3. **垫高 1–2 cm** —— 破开「贴着桌面」这条传导路径。木桌、软垫、地毯、布都是绝热体。

**验证方法**：改造前后各跑一段 `tools/Monitor-Temps.ps1`，对比平均温度。

## 五、要买风扇的话：大直径 + 低转速

| | 转速 | 噪音 |
|---|---|---|
| 塔式散热器自带小风扇 | 1500–2500 rpm | 明显可闻 |
| **120 mm 机箱风扇接 USB 5V** | **≈ 500–800 rpm** | **通常低于环境底噪** |

**5 V 的 120 mm 风扇仍有 ~30–40 CFM 风量，噪音往往比硬盘自己的寻道声还小。**

### 别买这些

| ❌ | 为什么 |
|---|---|
| **CPU 塔式散热器** | 它靠「芯片 → 金属底座 → 热管 → 鳍片」的**金属接触传导**工作。硬盘盒没有那条路径，摆旁边只会**挡住风**，而且它自带的高速小风扇比大直径低速风扇**更吵** |
| **笔记本散热垫** | 它的风只沿一层水平面往上吹，被 3.5" 盒子整个挡住 |
| **M.2 铝散热片** | 那是给 NVMe 的 |

## 六、测热余量时：阈值留 −6 ~ −8 ℃，不是 −2

**实测教训。** 我们设了「到上限 −2 ℃ 就停」：

```
13:51:28   盘报 53 ℃ → 自动停止负载
14:12      爬到 57 ℃ 并卡在那里（上限 55）
```

**驱动器的温度读数滞后于它的实际热状态。** 在读数 53 时停手，实际冲到了 57 —— 比阈值高约 **4 度**。

要保证「绝不超过上限」，阈值得设成 **上限 − 6 ~ −8 ℃**。`tools/Temperature-Watchdog.ps1` 的 `-Margin` 默认就是 **6**。

## 七、零电缆的替代方案：空闲自动停转

对**备用 / 归档盘**，让它在空闲时停转是最彻底的散热 —— 不转就不发热：

```powershell
& $sc -s standby,240 -d sat /dev/sdX      # 240 × 5 秒 = 20 分钟空闲后停转
```

**代价与注意：**

- ⚠️ **增加磁头加载循环**（真实的寿命消耗，不是白拿）
- ⚠️ **跑扩展自检前必须关掉** —— 停转会中止自检（见 [03](03-bridge-idle-spindown.md)）
- ⚠️ **任何定期轮询都会一直把它唤醒** —— 用这个方案时别同时挂温度监控

## 八、⚠️ 冷凝水：一个能直接干掉硬盘的风险

用**冰瓶 / 冷媒**给盒子降温是有效的应急手段（铝壳导热好，接触冷源能把整块壳拉凉，实测让目标盘降了 5 °C、被直接接触的那块降了 11 °C），**但有个真实风险**：

```
冰瓶表面 4 ℃ ＋ 室内空气 25 ℃ / 60% RH  →  露点约 17 ℃
    ↓
瓶子大量结露（这就是它「出汗」的原因）
    ↓
水顺壳流下 → 从缝隙 / 散热孔渗进盒内 → 落到硬盘 PCB 上 → 腐蚀 / 短路
```

**而且拿掉冷源之后还会继续结露** —— 壳是冷的，回暖过程中水继续凝。

如果一定要用：

1. **毛巾包住冷源**（吸水 + 隔断，冷却效果打折但还能用）
2. 冷源和壳体之间**垫一层塑料膜**，让水往旁边流
3. 下面**垫碟子 / 纸巾**
4. **别放着过夜**

**它真正值得用的场合：诊断。** 冷源放在哪块盘上，哪块盘降得多 —— 就说明哪块盘和壳的耦合更好，也就说明「从外面吹风」这条路对它是通的。这次实验就是这样确认了「铝壳和盘体之间有耦合，所以风扇路子是对的」。

## 九、小结：一个可以照做的流程

```powershell
# 1) 拿每块盘自己的上限
foreach ($d in 'sdf','sdc','sdg') {
    & $sc -l devstat -d sat "/dev/$d" | Select-String 'Specified Maximum|Highest Temperature|Time in Over-Temperature'
}

# 2) 跑一段空载温度记录（改造前）
.\tools\Monitor-Temps.ps1 -Serials <sn1>,<sn2> -Hours 2

# 3) 做免费改造：不叠放、立起来留缝、垫高

# 4) 再跑一段，对比平均温度

# 5) 要加负载测试时，用看门狗兜底（Margin 用 6）
.\tools\Temperature-Watchdog.ps1 -Serials <sn1> -Margin 6 -MaxHours 3
```

**验收标准（3.5" 机械盘，家用环境）：**

| 工况 | 目标 |
|---|---|
| 空载稳态 | ≤ 上限 − 15 °C |
| 负载峰值 | ≤ 上限 − 5 °C |
| 超限时间占比 | **0 %** —— 这一项任何非零值都说明摆放要改 |
